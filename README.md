### 🔭 What I'm working on

- **[alex-radar](https://github.com/yaojiejia/agents-radar)**: an automated daily radar for
  the AI open-source ecosystem. A GitHub Actions pipeline scans 16 repos (Claude Code, Codex,
  vLLM, SGLang, Ollama, ...) plus ArXiv, Hacker News, and GitHub Trending every night, and
  publishes data-driven digests with LLM-written summaries.
  **📡 Read it live → [yaojiejia.github.io/agents-radar](https://yaojiejia.github.io/agents-radar/)**
- **[nanoinfer](https://github.com/yaojiejia/nanoinfer)**: a minimal LLM inference engine,
  built to understand serving from first principles.
- **[AIBrix](https://github.com/vllm-project/aibrix)**: contributing to the vLLM project's
  cost-efficient, pluggable infrastructure layer for GenAI inference.
- **[Semantic Router](https://github.com/vllm-project/semantic-router)**: contributing to a
  programmable Mixture-of-Models router for heterogeneous LLM inference.
- **[Hermes Agent](https://github.com/nousresearch/hermes-agent)**: contributing to
  NousResearch's personal AI agent that grows with you.
